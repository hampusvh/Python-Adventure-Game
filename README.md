# Python Text Adventure

A text-based adventure game built with Python, featuring branching story paths, player-driven decisions, and basic game logic.

The game focuses on choice-based progression, where player decisions determine outcomes through predefined story paths and random events.

---

## Overview

This project is a command-line adventure game where players navigate a branching narrative by making decisions at key points in the story. Certain choices may immediately end the game, while others trigger encounters or random events that influence the outcome.

The game is designed to be replayable, offering multiple paths and scenarios rather than a single fixed ending.

---

## Features

- Text-based gameplay through the command line
- Branching story paths driven by player choices
- Randomized events triggered by dice-based mechanics
- Multiple possible outcomes and endings
- Replayable structure with alternative scenarios

---

## Tech Stack

- Python 3

---

## How to Run Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/hampusvh/python-text-adventure.git
   ```

2. Navigate to the project directory:
   ```bash
   cd python-text-adventure
   ```

3. Run the game:
   ```bash
   python main.py
   ```
